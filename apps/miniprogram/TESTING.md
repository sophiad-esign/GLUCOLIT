# 体验版验收清单

- [ ] iOS 和 Android 真机均可打开“餐食分析”页。
- [ ] 可使用相机拍照，也可从相册选择图片。
- [ ] 正常餐食返回菜品、份量、热量区间及五项营养估算。
- [ ] 结果展示餐盘平衡分、升糖负荷、行动建议和不确定性。
- [ ] 模糊图片、非食物图片、非支持格式和超过 5MB 的图片均有明确提示。
- [ ] 原始图片未写入数据库或对象存储。
- [ ] 连续点击不会产生并发识别请求。
- [ ] 小程序构建产物中不存在 `OPENAI_API_KEY` 或 `KIMI_API_KEY`。
- [ ] `request` 和 `uploadFile` 合法域名均配置为生产 API 的 HTTPS 主域名。
- [ ] API 无模型密钥或模型不可用时，小程序展示可理解的错误提示。
- [ ] 页面明确标注结果是照片估算和健康教育，不是诊断或医疗营养处方。
- [ ] 使用降糖药、妊娠、肾病或有低血糖史的人群能看到就医/营养师提醒。
