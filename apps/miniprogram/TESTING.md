# 体验版验收清单

## 导入与导航

- [ ] 使用真实 AppID 导入 `apps/miniprogram`，无编译错误。
- [ ] 底部导航依次显示：首页、AI、行动、指南。
- [ ] 品牌头部“切换”可进入“我的”页面。
- [ ] iOS 与 Android 真机均无文字截断、横向溢出或底部遮挡。

## 首页

- [ ] 展示健康概览、健康分、趋势图和今日三指标。
- [ ] 新用户可看到“待录入”状态，而不是伪造血糖值。
- [ ] 保存饮食、睡眠、运动或血糖后，返回首页能看到最新摘要。
- [ ] 首页行动按钮可进入 AI 和行动页面。

## AI 报告解读

- [ ] 可拍摄或选择 OGTT/HbA1c 报告。
- [ ] OCR/模型结果进入数值确认页，不直接当作医学结论。
- [ ] 用户修正数值后可生成中性化解释。
- [ ] 报告含姓名或证件信息时，页面有遮挡提醒。

## AI 餐盘分析

- [ ] 正常餐食返回食物、份量、热量和营养范围。
- [ ] 展示餐盘平衡分、波动风险、行动建议及不确定性。
- [ ] 非食物、模糊图片、超 5MB 和不支持格式均有明确提示。

## AI 配料表分析

- [ ] 可拍摄配料表和营养成分表。
- [ ] 返回添加糖、精制碳水、蛋白质、膳食纤维及选购建议。
- [ ] 模型偶尔返回单句建议时仍能正常解析。
- [ ] 结论使用中文状态，不暴露内部枚举。

## 行动与记录

- [ ] 核心行动可打卡并在重启页面后保留状态。
- [ ] 展示“怎么做 / 为什么做 / 做不到时”三段式。
- [ ] 可记录饮食餐次、睡眠、运动、空腹及餐后血糖。
- [ ] 最近七日记录可正常展示。

## 指南与我的

- [ ] 指南文章可筛选、打开详情并看到来源。
- [ ] 网络失败时可展示缓存内容和可理解提示。
- [ ] “我的”页面可查看隐私说明。
- [ ] 删除本机数据前有二次确认，删除后相关记录确实清空。

## 安全与合规

- [ ] 构建产物中不存在 `KIMI_API_KEY`、`OPENAI_API_KEY` 或 Vercel Token。
- [ ] 原始上传图片未写入数据库或对象存储。
- [ ] AI 输出中的疗效、极限和不当医学断言经过语言过滤。
- [ ] 所有核心页面展示健康教育免责声明。
- [ ] `request` 与 `uploadFile` 合法域名均已配置为生产 HTTPS 主域名。
- [ ] 隐私政策、用户协议、敏感信息授权和数据删除路径已在公众平台同步配置。
